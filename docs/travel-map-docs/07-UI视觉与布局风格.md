# 07｜UI 视觉与布局风格（对齐 geo-blog）

> 目标：在不复制具体实现的前提下，对齐你偏好的整体 UI 氛围与布局原则，作为后续页面/组件设计的统一参照。

## 1. 已确认的 UI 风格取向

- ✅ 暗色基调 + 蓝色强调（“暗色 + 霓虹蓝”氛围）
- ✅ 地图全屏沉浸：地图占满屏幕，UI 作为浮层叠加，不挤占主视图
- ✅ 强动效与过渡：交互反馈清晰、过渡顺滑
- ✅ 卡片式信息密度：信息以卡片/胶囊/抽屉面板呈现

## 2. 布局原则（推荐）

### 2.1 地图作为背景舞台
- 地图永远是视觉中心（full-bleed）
- 所有控制与信息展示以浮层叠加（panel/drawer/pill/card）

### 2.2 信息分区（与你的功能匹配）
- 顶部：导航（可选极简）
- 右侧：城市抽屉（核心：旅行次数目录、编辑与查看）
- 右上角：轻量控制面板（如：搜索、返回层级、设置）
- 地图内：POI 点 + hover tooltip（尽量轻）

## 3. 视觉语言（建议约束）

### 3.1 色彩（建议）
- 背景：neutral-950 ~ neutral-900
- 面板：黑色/深灰 + 透明度（5%~15%）+ blur
- 强调色：蓝（用于按钮、选中态、路径、关键数字）
- 警告/危险：红（删除、未保存）

### 3.2 材质（建议）
- Glassmorphism：半透明背景 + backdrop-blur + 细边框（低对比）
- Shadow：用于浮层与地图区分层级（避免太厚重）

### 3.3 字体与信息密度
- 标题：稍大、粗体，少字
- 辅助信息：小号、提高字间距（upper/数字/时间）
- 表单：强调可读性与“保存/未保存”状态提示

## 4. 动效（建议基线）

- hover/press：100–150ms
- 卡片弹出：spring（或 200–300ms ease-out）
- 抽屉打开/关闭：250–400ms
- 省级镜头缩放平移：500–800ms（已在交互规范中确认）

## 5. 待确认（影响 UI 结构的关键点）

1) 右侧抽屉结构
- ✅ 已确认：采用**三段式**信息架构：
  1. 城市主页（简介/封面/统计）
  2. 旅行次数列表
  3. 旅行详情编辑（表单 + Markdown 正文 + 附件管理）

2) 顶部是否需要全局搜索框（城市/POI/旅行）？

3) 旅行详情编辑布局
- ✅ 已确认：**左侧表单 + 右侧正文/附件**（工作台式布局）

4) 右侧区域信息组织
- ✅ 已确认：右侧采用 **“正文 / 附件” 两个 Tab**（更干净，附件多时更好管理）

5) 正文插入图片交互
- ✅ 已确认：正文支持 **粘贴/拖拽图片 → 自动入库并插入正文**（最顺手）
