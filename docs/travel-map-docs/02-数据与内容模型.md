# 02｜数据与内容模型

> 目标：明确“你需要准备/录入什么数据”，以及应用内部建议存成什么结构（便于先完成本机闭环，后续如有需要再扩展）。

## 1. 基础行政区（底图关联）

### 1.1 省（Province）
- `province_id`（建议用国家统计局行政区划代码或与底图数据一致的 code）
- `name`

### 1.2 地级市（City）
- `city_id`（同上）
- `province_id`
- `name`

> ✅ 已确认：第一版只做中国，层级到“地级市”

## 2. 城市内容（City Profile）

每个城市一份“主页内容”：
- `city_id`
- `summary`：城市简介（短文）
- `cover_asset_id`：城市封面图
- `tags[]`：城市标签（可选）
- `created_at / updated_at`

## 3. 旅行记录（按旅行次数）

> ✅ 已确认：城市目录按“旅行次数/每次出行”组织；且这些字段都需要。

每次旅行（Trip）建议字段：
- `trip_id`
- `city_id`
- `title`：例如“2026 清明杭州 3 天游”
- `date_start / date_end`：日期范围 ✅
- `companions[]`：同行 ✅
- `route`：路线（可文本/可按天拆分）✅
- `cost_total`：总花费 ✅
- `cost_breakdown`：分类花费（交通/住宿/餐饮/门票/其他）✅
- `tags[]`：标签 ✅
- `poi_list[]`：地点清单（关联 POI，可排序）✅
- `cover_asset_id`：旅行封面图 ✅
- `content`：正文（攻略/笔记/避坑/心得）✅
- `assets[]`：图片/文档附件引用 ✅
- `created_at / updated_at`

## 4. POI 地标点（地图点标记）

> ✅ 已确认：地图上展示可点击 POI 点标记。

POI（Point of Interest）建议字段：
- `poi_id`
- `city_id`
- `name`
- `lng / lat`：坐标（经纬度，**WGS84**）✅ 已确认
- `gcj02_lng / gcj02_lat`：坐标缓存（**GCJ-02**，用于渲染到高德底图与调试）✅ 已确认
- `category`：景点/美食/酒店/交通/拍照点/其它
- `tags[]`
- `summary`：简介
- `assets[]`：照片/文档（可选）
- `linked_trip_ids[]`：关联到哪些旅行记录（可选）
- `created_at / updated_at`

坐标转换约定（重要）：
- ✅ 已确认：数据库内部统一存 **WGS84**
- 高德地图的选点/搜索等结果通常为 **GCJ-02**：入库前需 GCJ-02 → WGS84；展示到高德地图前需 WGS84 → GCJ-02

> ❓ 待确认：POI 的录入方式（地图点选 / 粘贴坐标 / 导入 / 混合）

## 5. 资源与附件（图片/文档展示）

统一的资源表（Asset）建议字段：
- `asset_id`
- `type`：image / pdf / doc / md / link / other
- `filename`
- `mime`
- `size`
- `storage_path`：本地存储路径（桌面应用）
- `caption`：说明（可选）
- `created_at`

> ✅ 已确认：需要图片展示与文档展示能力。

附件落盘约定（已确认）：
- ✅ 已确认：附件按 **城市 / 旅行** 目录结构存储（详见《06-存储与附件规范》）

## 5.1 备份与导出（已确认）

- ✅ 已确认：导出为 **zip 全量**  
  - 至少包含：数据库文件 + 全部图片/文档附件 +（可选）导出清单（manifest）

## 6. 数据准备清单（你需要“整理/录入”的东西）

### 6.1 必备（第一版跑通闭环）
1) 城市简介（至少 1 个城市）
2) 城市封面图（至少 1 张）
3) 每次旅行记录（至少 2 次）
4) 每次旅行的图片/正文
5) POI：至少 5–10 个（含坐标）

### 6.2 建议最小样本（用于验证体验）
- 2 个省
- 每省 2–3 个地级市
- 1 个城市做“完整内容示例”
