# 00｜项目总览

## 1. 项目一句话

做一个**以中国地图为入口**的个人旅行知识库：从省份进入地级市，点击城市后在右侧抽屉查看/编辑旅行记录、图片、攻略与本地资料，并在地图上以 POI 点的形式标注地标与收藏。

## 2. 第一版范围（MVP）

- 地图范围：**仅中国** ✅ 已确认  
- 层级：**全国 → 省 → 地级市** ✅ 已确认  
- 省内：展示地级市边界 ✅ 已确认  
- 城市内容：右侧抽屉展示 ✅ 已确认  
- 目录组织方式：按“旅行次数/每次出行”组织 ✅ 已确认  
- 地标：地图上展示可点击 POI 点标记 ✅ 已确认  
- 运行形态：桌面应用，当前先完成本机闭环 ✅ 已确认  

> 非目标（第一版暂不做）
> - 世界地图 / 其它国家行政区深入
> - 公共发布平台、搜索引擎收录、多人协作
> - R2 同步、登录体系、多设备访问

## 3. 用户故事（你真正要完成的事情）

1) 我打开应用，看到中国地图。  
2) 我点“浙江省”，地图镜头缩放平移进入浙江，出现各地级市边界。  
3) 我点“杭州市”，地图不移动，高亮杭州，右侧抽屉打开。  
4) 我在抽屉里看到我去杭州的第 1 次旅行、第 2 次旅行……点进去能看笔记、图片、攻略与相关文件。  
5) 我在地图上看到一些 POI 点（景点/美食/酒店/拍照点等），点 POI 能看到简介、照片，并能关联到某次旅行记录。  

## 4. 成功标准（判断第一版是否“可用”）

- 能顺畅完成“省 → 市 → 打开抽屉查看内容”的闭环
- 城市内容支持：文字（长文）+ 图片展示 + 文档/附件展示
- 旅行记录字段完整（见《02-数据与内容模型》）
- POI 能在地图上点选/管理（具体录入方式待定，见《05-未决问题清单》）
