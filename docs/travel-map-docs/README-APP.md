# 🗺️ Travel Map Journal（暂定名）

> 一个以“中国地图”为入口的个人旅行记录系统：省 → 地级市 → 城市抽屉。  
> 支持站内编辑：旅行记录（按次数）、POI 地标、图片与文档附件。本机优先，后续可上云同步。

---

## ✨ 你能用它做什么？

- 在中国地图上快速定位：**点省 → 点市 → 打开城市抽屉**
- 按“旅行次数”管理同一城市的多次出行记录
- 在地图上用 **POI 点标记**沉淀地标（景点/美食/住宿/交通/拍照点…）
- 记录与归档：文字笔记 + 图片相册 + PDF/Word/票据等附件
- 一键导出 **zip 全量备份**（重点包含图片与附件）

---

## ✅ 已确认的产品范围（MVP）

- 地图范围：仅中国
- 层级：全国 → 省 → 地级市
- 省级进入：镜头缩放平移（500–800ms，标准自然）
- 市级点击：地图不移动，仅高亮并打开右侧抽屉
- 目录组织：按“旅行次数/每次出行”
- POI：地图上可点击点标记
- 未保存提醒：切换/退出时提示是否保存

## 🧱 核心架构（规划）

| 层级 | 技术/模块 | 说明 |
|---|---|---|
| 🖥️ 桌面外壳 | **Electron** | Windows + macOS，本机运行优先 |
| 🎨 UI | React（暂定） + Tailwind（可选） | 组件化 UI，右侧抽屉承载内容编辑与展示 |
| 🗺️ 地图底图 | **高德地图（AMap）** | 道路/卫星底图、POI 搜索、地理编码/逆地理编码（按需接入） |
| 🧭 行政区层级 | 省/市边界数据（GeoJSON/TopoJSON） | 用于省→市层级点击与高亮（与底图叠加） |
| 💾 数据存储 | **SQLite（本机）** | 结构化数据：城市/旅行/POI/标签/花费等 |
| 🗂️ 附件存储 | 本地附件目录（Asset） | 图片/文档落盘，DB 记录元数据与路径 |
| ☁️ 同步（后续） | 服务端 + 对象存储 | 第二阶段：登录、多设备访问与同步 |

## 📍 坐标体系约定（关键）

为保证长期可迁移与跨地图引擎兼容：

- **数据库内部统一存 WGS84** ✅  
- 同时在 POI 表中 **缓存 GCJ-02 坐标**（`gcj02_lng/gcj02_lat`）✅  
- 与高德交互时：在读写边界进行坐标转换（GCJ-02 ↔ WGS84）

## 🧩 数据模型一览（简化版）

- Province（省）
- City（地级市）
- CityProfile（城市主页：简介/封面/标签）
- Trip（旅行记录：日期范围/同行/路线/花费/标签/地点清单/封面/正文/附件）
- POI（地标点：名称/类别/标签/简介/坐标/附件/关联旅行）
- Asset（图片/文档：类型/mime/大小/本地路径/说明）

详情见：[`travel-map-docs/02-数据与内容模型.md`](./02-数据与内容模型.md)

## 🗺️ 里程碑（建议）

1. **M0 可点击中国地图**：省级边界 + 进入省动效  
2. **M1 省内地级市 + 城市抽屉**：点击市高亮 + 抽屉切换  
3. **M2 旅行记录闭环**：新建/编辑/展示 + 图片/附件  
4. **M3 POI 点标记闭环**：点选/编辑/关联旅行  
5. **M4 Electron 打包**：Windows/macOS 安装包  
6. **M5 上云同步**（第二阶段）

详情见：[`travel-map-docs/04-里程碑与待办Backlog.md`](./04-里程碑与待办Backlog.md)
