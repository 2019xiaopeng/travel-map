# 2026-05-08 地图与侧边栏重构设计

## 状态
- 已完成设计确认
- 设计基线：以文档为主，允许适度优化
- 边界数据策略：优先真实数据，缺失时降级提示，不再伪造假边界
- 侧边栏策略：省级弱侧栏，城市强侧栏

## 背景
- 当前全国层省界视觉粗糙，边界与标签存在不贴合问题。
- 省级城市边界在缺少真实数据时会退化为假形状，直接破坏可信度与观感。
- 抽屉控制入口重复，右上角、左上角、右侧把手语义重叠，交互不稳定。
- 侧边栏在省级和城市级的信息结构不清晰，没有形成文档预期中的主工作流。

## 对照文档后的主要问题
- 全国层应承担省级识别与进入，但当前省级边界、标签与聚焦结果不稳定。
- 省级层应承担城市选择，点击城市时不应再次大幅移动镜头，但当前仍存在二次聚焦。
- 右侧面板应是稳定的 UI 舞台，而非多个零散按钮共同控制的漂浮对象。
- 地图应保持暗色、轻 UI、玻璃态浮层，但当前边界颜色和标签密度破坏了整体质感。

## 目标
- 修复全国层与省级层边界“不贴合、难看、层级混乱”的核心问题。
- 用真实边界数据替代现有假数据 fallback，确保视觉和语义可信。
- 重做右侧侧边栏的信息架构与控制方式，让其成为稳定、明确、可持续扩展的主工作区。
- 以较小的交互复杂度恢复“全国 -> 省 -> 城市”的地图主流程，并与文档定义保持一致。

## 设计 A：总体结构
### 1. 地图交互分层
- 地图交互拆为全国层与省级层两段。
- 全国层负责省级识别、hover、高亮、点击进入省级并聚焦。
- 省级层负责城市识别、轻量标签、打开详情，不再默认对城市做二次大幅 fitView。
- 城市详情打开后，地图保持相对稳定，右侧强侧栏承担主阅读与操作任务。

### 2. 边界数据与标签
- 边界数据只认真实 GeoJSON。
- 禁止使用矩形 fallback 或其他伪造轮廓。
- 数据缺失时用清晰提示说明“该地区边界数据未就绪”。
- 标签位置优先使用真实 center；缺失时使用更可靠的几何中心算法，避免标签漂移和压线。

### 3. 侧边栏状态模型
- 侧边栏改成单一状态源。
- 国家级不显示正式侧边栏。
- 省级显示弱侧栏，承担省份概览与城市入口。
- 城市级显示强侧边栏，承载城市主页、行程列表、行程详情与 POI 详情。

### 4. 抽屉控制收敛
- 只保留一处主控制入口。
- `Esc` 作为辅助关闭能力。
- 关闭仅改变可见性，不清空当前上下文。
- 所有收起与展开行为都依赖同一状态流，不再允许多套按钮各自维护不同语义。

## 设计 B：交互与视觉重构细节
### 1. 边界视觉重构
- 全国层不再使用高饱和橙色粗线作为主视觉，改为更克制的冷白或青灰边界，hover 和选中态再使用强调色。
- 省级与市级使用两套明确的层级语言：
  - 省界更稳、更薄、更完整，负责“国家级行政识别”。
  - 市界更轻、更密、更局部，负责“省内城市选择”。
- 取消“面 + outline 双重抢眼描边”的画法，减少双线感、糊边和脏乱感。
- 标签密度按层级收敛，全国层仅保留省名，省级层按可读性显示城市名，并可结合缩放阈值控制显示数量。

### 2. 边界贴合与数据策略
- 删除所有假矩形 fallback。
- 省级下钻只使用真实城市 GeoJSON；没有数据就提示“该省份城市边界数据未就绪”，而不是画错误轮廓。
- 标签定位不再依赖粗糙均值中心，改为优先真实中心、其次更可靠几何中心。
- 地图聚焦 padding 统一为布局令牌，根据真实侧边栏宽度计算，避免地图内容被侧边栏侵占或留白不一致。

### 3. 侧边栏信息架构
- 省级弱侧栏：
  - 顶部显示当前省份身份。
  - 中部展示城市列表、简要统计或入口提示。
  - 底部放置轻量交互说明。
- 城市强侧栏：
  - 顶部为城市身份区与主操作。
  - 中部为城市主页摘要与旅行入口。
  - 深层内容继续承载旅行列表、旅行详情、POI 详情。
- 关闭侧边栏后不丢失当前城市上下文，重新展开时恢复最近视图。

### 4. 抽屉控制与导航
- 删除重复控制，不再同时保留右上角、左上角、右侧把手三套等价入口。
- `收起` 表示隐藏侧边栏但保留当前层级与上下文。
- 单独的 `关闭` 按钮仅在语义明确且有必要时保留，否则用 `收起` 统一表达。
- `Esc` 等价于 `收起`，不附带清空内容等副作用。
- 左上角面包屑仅承担导航职责，不再混入过多抽屉控制。

### 5. 地图交互对齐文档
- 点击省份：进入省级并聚焦到省域。
- 点击城市：默认只高亮并打开强侧栏，不再二次大幅挪镜头。
- hover 提示、高亮与选中态使用统一的过渡参数，避免突然闪变。
- 地图仍然是主舞台，提示层和控制层尽量少而准。

## 设计 C：实施拆分、风险控制与验收
### 1. 实施拆分
- 阶段 1：地图边界与数据源
  - 去掉假 fallback。
  - 统一全国层与省级层的真实边界加载策略。
  - 重算标签定位与聚焦 padding。
- 阶段 2：交互与侧边栏
  - 收敛抽屉状态模型。
  - 重做省级弱侧栏与城市强侧栏。
  - 清理重复按钮与不稳定事件链。
- 阶段 3：视觉统一
  - 重设省界、市界、标签、浮层视觉令牌。
  - 调整面包屑、提示条、侧边栏头部与内容层次。
- 阶段 4：验收与清理
  - 浏览器与 Electron 双通道验证。
  - 补必要的类型检查、诊断检查和回归测试。

### 2. 并行实施策略
- 将实施拆为 2 到 3 个并行子块：
  - 一组专注地图边界、GeoJSON、标签与聚焦。
  - 一组专注侧边栏、状态流与交互控制。
  - 一组在需要时处理视觉统一与验收辅助。
- 主控代理负责总装、冲突消解、统一验证、分阶段提交和最终验收。

### 3. 风险控制
- 最大风险是地图层与侧边栏状态互相影响，因此先统一状态源，再重接按钮与布局。
- 第二个风险是真实边界数据覆盖不完整，因此先确认可用数据范围，并为缺失场景提供明确降级提示。
- 第三个风险是视觉改动过大影响可读性，因此先修层级语言和布局，再做色彩与细节微调。

### 4. 验收标准
- 全国层省界准确、克制，不再出现刺眼粗线和明显漂移标签。
- 进入省级后城市边界仅来自真实数据；缺失时有明确提示，不出现假轮廓。
- 点击省份会进入并合理聚焦；点击城市不会再次大幅跳镜头。
- 右侧侧边栏形成清晰的省级弱侧栏与城市强侧栏。
- 抽屉只有一套主控制逻辑，`收起`、`展开`、`Esc` 行为稳定。
- 浏览器预览与 Electron 真窗口都能完成主流程。
- `pnpm typecheck` 与诊断检查通过。

## 不在本轮范围内
- 不在本轮引入新的地图供应商或更换为其他 GIS 绘制框架。
- 不在本轮重写城市主页、旅行详情、POI 详情的业务数据模型。
- 不在本轮扩展 R2 同步、备份恢复或 Markdown 编辑器能力。

## 实施前置结论
- 该任务适合先写实施计划，再进入并行编码。
- 编码时应优先处理地图真实边界与侧边栏状态模型，再做视觉统一。
