# 2026-05-09 搜索动画与省级 Hover 稳定性修复设计

## 状态
- 已完成设计确认
- 本轮聚焦两个回归问题：
  - 顶部搜索框关闭时直接消失，没有从右往左缩短的回收动画
  - 省份 hover 在全国层和省级/城市级都不稳定，highlight 和跟随 tag 会闪烁，鼠标静止时也可能消失

## 背景
- 上一轮为了拆开搜索框和提示气泡，`CitySearchBox.tsx` 采用了 `open` 为 `false` 时直接卸载内部内容的写法。
- 这导致关闭搜索时，DOM 先消失，再去做宽度变化，用户看到的就是“直接没了”，而不是一个完整的收缩过程。
- 同一轮为了在 `province` / `city` 视图中复用邻省切换能力，`ProvinceLayer.tsx` 新增了 overlay 模式。
- 当前 `ProvinceLayer` 同时渲染省面 `Polygon` 和高层级描边 `Polyline`；鼠标在省面和描边之间移动时，会频繁触发 `mouseout -> clear hover`，导致 highlight 与 tag 一闪一闪。
- 当前 hover 清空策略还是“立即清空”，只要事件短暂抖动，跟随 tag 就会被清掉，所以鼠标不移动时也会出现“看起来自己消失了”的现象。

## 目标
- 搜索框关闭时保留从右往左缩短的完整动画，而不是直接消失。
- 搜索结果面板与输入框在关闭过程中一起收回，但动画期间不再接受交互。
- 省份 hover 在全国层和省级/城市级都保持稳定：
  - 鼠标仍在省区域内时，highlight 与跟随 tag 持续保持
  - 鼠标跨越省面与描边时，不再闪烁
  - 鼠标停止移动时，tag 不会自己消失

## 非目标
- 本轮不重做整个地图 hover 架构。
- 本轮不改动搜索排序、搜索索引或城市相机逻辑。
- 本轮不新增新的 hover 视觉样式，只修复稳定性与动画连续性。

## 方案对比
### 方案 A：最小稳定性修复 `推荐`
- 搜索框常驻挂载，只通过 `width / opacity / transform / pointer-events` 控制开合状态。
- 搜索关闭时不立即移除结果容器，而是让它跟随输入框一起收缩并禁用交互。
- 省级 hover 继续复用现有 `ProvinceLayer` / `ProvinceHoverOverlay`，但调整图层事件优先级：
  - 让省面成为主要交互层
  - 让描边不再抢占 hover 事件
- `mouseout` 不再立刻清空 hover，而是采用短延迟清空；若短时间内重新进入同一省，则取消清空。
- 优点：改动集中，能直接修复两类回归。
- 缺点：仍保留现有按图层事件驱动 hover 的模式，未升级到更彻底的命中检测方案。

### 方案 B：改成容器级 hover 控制
- 不再依赖每个省 polygon 的 `mouseover/mouseout`。
- 改为容器级 `mousemove` 命中检测，再统一驱动 highlight 和 tag。
- 优点：从理论上最稳。
- 缺点：改动范围大，会牵涉全国层、省级 overlay、城市层之间的事件协调，超出本次 bugfix 范围。

### 方案 C：仅做延迟清空补丁
- 保留当前动画写法，只给搜索框补一点视觉过渡。
- hover 只做延迟清空，不调整省面与描边的事件层级。
- 优点：最快。
- 缺点：根因没有消除，hover 仍可能继续闪。

## 结论
- 采用 `方案 A：最小稳定性修复`。
- 目标是以最小改动恢复动画完整性，并修复省级 hover 在两种层级下的稳定性。

## 设计 A：搜索框回收动画恢复
### 1. 问题定义
- 当前 `CitySearchBox.tsx` 在 `open === false` 时直接卸载内部输入框和结果面板。
- 这会截断动画，导致用户只看到元素瞬间消失。

### 2. 修复策略
- 搜索框外层容器继续保留固定动画壳层，负责 `w-72 -> w-0` 的横向收缩。
- 输入框和结果层在关闭时也继续保留在 DOM 中，只切换：
  - `opacity`
  - `translate-x`
  - `pointer-events`
- 结果层在关闭时不再响应点击、hover 和键盘选择，但会随容器一起收回。

### 3. 目标
- 搜索框关闭时能明显看到从右往左缩短的回收动画。
- 动画期间不会因为容器已卸载而直接跳断。

## 设计 B：省级 Hover 稳定性恢复
### 1. 问题定义
- 当前 `ProvinceLayer.tsx` 里，省面 `Polygon` 和描边 `Polyline` 共存。
- 描边层级较高时，鼠标容易在“面”和“线”之间切换，频繁触发 `mouseout`。
- 当前 hover 一旦 `mouseout` 就立刻清空，所以 highlight 和 tag 会闪烁。

### 2. 交互规则
- 用户已明确选择：
  - 只要鼠标仍在该省区域内，即使不移动，highlight 和 tag 也持续保持。
- 因此 hover 清除条件必须从“事件一抖就清空”改成“确认已离开该省区域后再清空”。

### 3. 修复策略
- 省面 `Polygon` 继续作为主要 hover 命中层。
- 省描边 `Polyline` 改为不参与 hover 抢占：
  - 要么降低事件优先级
  - 要么直接禁用其鼠标命中
- `mouseout` 改为“短延迟清空”：
  - 先启动一个极短的清理定时器
  - 若期间收到新的 `mouseover / mousemove`，取消该清理
- 清理逻辑要与 `country` / `overlay` 模式共用，不再让两个模式出现不同手感。

### 4. 目标
- hover 到省份时，highlight 与跟随 tag 保持稳定。
- 鼠标跨过描边、停在省内、或轻微抖动时，不再出现一闪一闪。
- 鼠标真正离开省份后，tag 才消失。

## 模块边界
### 1. 搜索动画
- `CitySearchBox.tsx`
  - 负责搜索框壳层、输入框、结果面板的开关动画与交互禁用
- `BreadCrumbOverlay.tsx`
  - 保持搜索框容器布局，不再承担动画补丁职责

### 2. Hover 稳定性
- `ProvinceLayer.tsx`
  - 负责 hover 事件节流、延迟清空、面/线交互层级调整
- `ProvinceHoverOverlay.tsx`
  - 维持现有展示能力，不新增状态逻辑
- `MapView.tsx`
  - 保持统一持有 `provinceHover`，不增加第二套清理机制

## 错误处理
- 搜索框即使索引加载失败，也应保持正常开合动画。
- 若 hover 延迟清空逻辑异常，至少不能阻断省份点击切换。
- 若 overlay 模式下 hover 修复失败，也不能影响当前省城市层的浏览与点击。

### 2. 人工验收

- 在省级视图 hover 邻省时，highlight 和 tag 同样保持稳定。
- 鼠标停在省份内部不移动时，tag 不会自动消失。
- 鼠标真正离开省份后，tag 才消失。
