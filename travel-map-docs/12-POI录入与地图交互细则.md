# 12｜POI 录入与地图交互细则

> 目标：明确 POI 打点体验与“省→市下钻”的核心交互，避免实现阶段反复返工。

## 1. POI 录入方式（MVP 组合策略）

第一版采用组合方案（优先打磨单点体验）：

1) ✅ 主形态：地图点选添加 POI  
   - 交互建议：点击工具栏“添加地标”后在地图点击落点（桌面端避免右键冲突）  
   - 落点后弹出小表单：名称、分类、简介（可选）
2) ✅ 辅助形态：允许精确坐标编辑  
   - 在表单中提供经纬度字段，允许粘贴/微调
3) 暂不做：CSV/KML/GPX 批量导入（V1 不做，聚焦单点记录）

> 坐标约定：入库 WGS84；同时缓存 gcj02_lng/gcj02_lat（与高德交互时转换）。

## 2. 省 → 市边界数据与加载策略

### 2.1 数据源
可从公开资源下载中国行政区 GeoJSON（全国省级 + 各省地级市）。

### 2.2 本地打包 + 按省读取
建议把边界数据随 Electron 一起打包（容量通常不大）：

```text
packages/renderer/src/assets/geo/
├── china-provinces.json
└── provinces/
   ├── 330000.json   # 浙江（地级市）
   ├── 320000.json
   └── ...
```

加载策略：
1) 初始化：加载 `china-provinces.json`，渲染全国省界
2) 点击某省：读取 `provinces/{province_id}.json` 并替换/叠加为地级市边界层
3) 因为读取本地文件，无网络延迟，进入省内会很“丝滑”

## 3. 面包屑与回退（已采用方案）

在地图左上角提供悬浮面包屑（Overlay Breadcrumb）：
- 初始：`中国`
- 进入省：`中国 / 浙江省`
- 选中市并打开抽屉：`中国 / 浙江省 / 杭州市`

交互：
- 点击 `中国`：回到全国视图、关闭抽屉、恢复省界层
- 点击 `浙江省`：回到省视图、保持抽屉可按需求关闭或切换

> 具体实现：若使用高德地图，可用 setFitView / setZoomAndCenter 结合动画；若使用 SVG/D3 则用 d3-zoom 回退。

## 4. POI 聚合（Cluster）与展示控制

当 POI 数量很大（例如 300+）时需要聚合以保证性能与可读性：

- 若采用高德：优先使用官方 `AMap.MarkerClusterer`
- 若采用 SVG/D3：可使用 `supercluster` 在屏幕空间聚合

联动建议：
- 只有在缩放到足够级别、POI 脱离聚合成为独立点时，点击才进入抽屉或弹出 Popover
