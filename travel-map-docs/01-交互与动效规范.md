# 01｜交互与动效规范

## 1. 视图状态（State）

### 1.1 全国视图（China View）
- 显示：省级边界
- 交互：hover 高亮 + tooltip（省名）；click 进入省视图

### 1.2 省视图（Province View）
- 显示：该省的地级市边界
- 交互：click 某地级市，高亮该市并打开右侧抽屉

### 1.3 抽屉（Drawer）内容态
- 右侧抽屉常驻在 UI 层，不随地图缩放
- 城市切换时：抽屉内容切换（可带轻量过渡）

## 2. 关键交互（已确认）

### 2.1 点击省份：镜头缩放平移进入省内
- 动画形式：**镜头缩放 + 平移** ✅ 已确认  
- 动画节奏：**标准自然 500–800ms + easing（先快后慢）** ✅ 已确认  
- 目标：省份自动居中，缩放到“能清晰看到地级市边界”的级别

### 2.2 点击地级市：不移动镜头
- 点击某地级市时：**地图镜头不移动** ✅ 已确认  
- 地级市表现：
  - 边界高亮（描边加粗/颜色变化）
  - 填充轻量强调（可选）
  - 打开右侧抽屉（城市内容）

### 2.3 POI（地标点）点击
- POI 展示形式：地图上的可点击点标记 ✅ 已确认  
- 点击后：建议优先在抽屉中展示 POI 详情（或在地图上浮层 + 抽屉联动）

## 4. 动效与视觉建议（可调整）

- hover：100–150ms
- 高亮过渡：150–250ms
- 镜头缩放平移：500–800ms（已确认默认）
- 降级策略：性能不足时，动效可缩短或关闭
